% ============================================================
% Typographic scale — the single place any CV size is decided.
%
%   25pt  name              the header
%   13pt  section heading   Experience, Skills, ...
%   12pt  company           1. Oivan
%   11pt  role              Real Estate Product
%   10pt  body              every bullet and every line of prose
%
% \bfseries goes before \selectfont so the weight is part of the
% font actually selected, not applied to an already-chosen one.
% ============================================================
